# 第6章：繰り返し処理

## 対応するC規格

- **主要対象**：C90
- **学習内容**：`for`、`while`、`do-while`、`break`、`continue`、入れ子のループ

## 学習目標

この章では、同じような処理を条件に合わせて何回も自動で繰り返す**繰り返し処理**（**ループ**）を学びます。
たとえば「1から100までを足す」「テストの点数を全員分表示する」といった作業を、短いコードで書けるようになります。

- 繰り返す回数や終わる条件に合わせて、適切なループを選べる
- `for`文の3つの式がどの順番で実行されるかを説明できる
- `break`と`continue`がどのループをどう動かすかを説明できる
- 配列の範囲をはみ出さない安全なループを書ける

## `for`文

`for`文は、「5回繰り返す」「0から9まで繰り返す」のように、繰り返す回数や範囲がはっきりしているときによく使うループです。
ループに必要な3つの要素を1か所にまとめて書きます。

```c
for (initialization; condition; iteration) {
    statement;
}
```

カッコの中の3つの役割は次のとおりです。

- `initialization`（**初期化**）：ループを始める前に1回だけ行う準備です（例：カウンターを0にする）
- `condition`（**継続条件**）：ループを続けるかどうかを調べる条件です
- `iteration`（**反復式**）：中身を1回実行し終わるたびに動く更新処理です（例：カウンターを1増やす）

実行される順番は次のとおりです。

1. 初期化を1回だけ実行する
2. 継続条件を調べる
3. 条件が0（偽）ならループを終了する
4. 波括弧`{ }`の中身（本体）を実行する
5. 反復式を実行し、手順2へ戻る

C90では、ループの回数を数える変数（ループ変数）を`for`文より前で宣言します。

```c
#include <stdio.h>

int main(void)
{
    int i;

    for (i = 0; i < 5; i++) {
        printf("%d\n", i);
    }

    return 0;
}
```

このプログラムでは、`i`が`0`からスタートし、`i < 5`のあいだ1ずつ増えながら画面に表示されます。
つまり`0`、`1`、`2`、`3`、`4`の5回が表示され、`i`が`5`になったところで`i < 5`が偽になり、ループが終わります。

また、データを並べて管理する**配列**を先頭から末尾まで順番に処理するときは、番号（**添字**）の始まりと終わりの条件を配列の要素数に合わせます。

```c
int values[5] = { 10, 20, 30, 40, 50 };
int i;

for (i = 0; i < 5; i++) {
    printf("%d\n", values[i]);
}
```

C言語の配列の番号は`0`から始まるため、5個の要素がある場合の番号は`0`から`4`までです。
もし条件を`i <= 5`と書いてしまうと、最後の回で存在しない`values[5]`（6個目）にアクセスしてしまい、配列の範囲をはみ出す危険なバグになります。

## `while`文

`while`は英語で「〜のあいだ」という意味です。
`while`文は、繰り返す回数が前もって決まっておらず、「ある条件を満たしているあいだずっと続けたい」ときに使います。

`while`文は、中身を実行する**前**に継続条件を調べます。
そのため、最初から条件が偽だった場合は、中身が1回も実行されずに終わります。

```c
while (condition) {
    statement;
}
```

次は、キーボードから数字を読み込みながら、「正しく数字が入力され、しかも0より大きいあいだ」繰り返す例です。

```c
#include <stdio.h>

int main(void)
{
    int number;

    while (scanf("%d", &number) == 1 && number > 0) {
        printf("value: %d\n", number);
    }

    return 0;
}
```

`scanf`関数は、キーボードなどからデータを読み込む関数です。
この例では、整数を1個うまく読み込めたときに`1`を返します。
文字など整数にできないものが入力されたときは`0`を、入力の終わりや読み取りエラーが起きたときは`EOF`（データの終わりを表す特別な値）を返します。

そのため、`scanf("%d", &number) == 1 && number > 0`と書くことで、入力ミスを防ぎながら0以下の数が入力されたら安全にループを終えられます。

## `do-while`文

`do-while`文は、中身を**先に1回実行してから**、最後に継続条件を調べるループです。
この文にたどり着いた場合、たとえ最初から条件が偽であっても、中身は**必ず最低1回は実行されます**。

```c
do {
    statement;
} while (condition);
```

`while (condition)`の最後に**セミコロン`;`が必要**なので、書き忘れないように注意してください。

たとえば、メニュー画面を最低1回は表示して、ユーザーに「続けるか、終わるか」を選んでもらう場面に向いています。

```c
#include <stdio.h>

int main(void)
{
    int choice;

    do {
        printf("1: continue, 0: exit\n");

        if (scanf("%d", &choice) != 1) {
            return 1;
        }
    } while (choice != 0);

    return 0;
}
```

このプログラムは、まずメニューを表示して数字を受け取ります。
もし数字以外が入力されたら（`scanf`の戻り値が`1`でないとき）、エラーとして`return 1;`でプログラムを終わらせます。
`0`以外の数字ならもう一度メニューを表示し、`0`が入力されたらループを終了します。

## `break`文

`break`文は、ループの途中でもその場で強制終了して外へ脱出する命令です。
もっとも内側にあるループ（または`switch`文）を終わらせます。

```c
int i;

for (i = 0; i < 100; i++) {
    if (i == 5) {
        break;
    }

    printf("%d\n", i);
}
```

この例では、`i`が`0`から`4`までは画面に表示されますが、`i`が`5`になった瞬間に`break`が実行されてループが終わります。
そのため、100回まで待たずに途中で処理を止められます。

ただし、ループの中にさらにループがある（入れ子のループ）場合、`break`で抜けられるのは**一番内側のループだけ**です。
外側のループも一緒に止めたいときは、「見つかったかどうか」を記録する目印の変数（**フラグ**）を使ったり、処理を関数に分けて`return`で一気に抜けたりします。

次の例では、3×3の表`matrix`の中から目的の値`target`を探し、見つかったら外側のループも止めるためにフラグ`found`を使っています。

```c
int row;
int column;
int found = 0;

for (row = 0; row < 3 && !found; row++) {
    for (column = 0; column < 3; column++) {
        if (matrix[row][column] == target) {
            found = 1;
            break;
        }
    }
}
```

最初は`found`を`0`（まだ見つかっていない）にしておきます。
目的の値が見つかったら`found = 1;`（見つかった）に変えて`break`で内側のループを抜けます。
すると外側のループの条件`!found`（「まだ見つかっていないあいだ」）が偽になるため、外側のループもきれいに終わります。

## `continue`文

`continue`文は、ループ自体を終わらせるのではなく、「今回の1回分だけ残りの処理を飛ばして、次の回へ進む」命令です。
`for`文では反復式（`i++`など）へ、`while`文と`do-while`文では継続条件のチェックへ進みます。

次の例では、1から10までのうち奇数だけを表示します。

```c
int i;

for (i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;
    }

    printf("%d\n", i);
}
```

`%`は割り算の余りを求める記号です。
`i % 2 == 0`（2で割り切れる偶数）のときだけ`continue`が実行され、`printf`を飛ばして次の`i++`へ進みます。
その結果、`1`、`3`、`5`、`7`、`9`だけが表示されます。

`while`文で`continue`を使うときは、1つ大事な注意点があります。
カウンターを増やす処理より前に`continue`を書いてしまうと、カウンターが永遠に増えず、ループが終わらなくなる（無限ループになる）ことがあります。

```c
int i = 0;

while (i < 10) {
    i++;

    if (i % 2 == 0) {
        continue;
    }

    printf("%d\n", i);
}
```

このように、`continue`より前に`i++;`を置いておけば、スキップされても確実に`i`が増えるため安全です。

## 入れ子のループ

ループの中にさらに別のループを入れたものを**入れ子のループ**と呼びます。
九九の表や、縦（行）と横（列）がある2次元の表・配列を処理するときによく使います。
一般的には、外側のループで「行」を、内側のループで「列」を進めます。

次の例は、3×3のかけ算の表を表示します。

```c
int row;
int column;

for (row = 1; row <= 3; row++) {
    for (column = 1; column <= 3; column++) {
        printf("%d ", row * column);
    }

    printf("\n");
}
```

外側の`row`が`1`のとき、内側の`column`が`1`、`2`、`3`と変化して`1 2 3`と表示され、内側のループが終わると`printf("\n");`で改行します。
次に`row`が`2`になって`2 4 6`と表示され、最後に`row`が`3`で`3 6 9`と表示されます。

入れ子のループでは、外側が`m`回、内側が各回`n`回動くと、一番内側の処理は合計で`m * n`回実行されます。
たとえば1000×1000なら100万回になります。
データ量が多いときは、実行回数が増えて処理に時間がかかりすぎないかも確認しましょう。

## 無限ループ

継続条件を省略した`for (;;)`や、ずっと真になる`while (1)`は、中で`break`などを使って止めない限り、ずっと繰り返され続けます。
これを**無限ループ**と呼びます。

```c
for (;;) {
    if (should_stop()) {
        break;
    }

    process_one_item();
}
```

```c
while (1) {
    if (should_stop()) {
        break;
    }

    process_one_item();
}
```

ゲームのメイン処理や、ユーザーからの操作・通信を待ち続けるプログラム（イベントループや待受処理）では、わざと無限ループを使うことがあります。
無限ループを書くときは、「どんなときに終わるのか」「エラーが起きたらどうするか」「外からどうやって止められるか」を必ず設計してください。

## ループを安全に書く

ループは少しの書き間違いで、プログラムが止まらなくなったり、メモリを壊してしまったりすることがあります。
安全に書くための3つのポイントを確認しましょう。

### 境界を式で対応させる

配列の要素数（たとえば`10`）をループの条件に直接書くと、後から配列のサイズを変えたときに修正し忘れてバグになることがあります。
配列そのものが見える場所では、要素数を式で計算しておくと安全です。

```c
#include <stddef.h>

int values[10];
size_t i;
size_t count = sizeof values / sizeof values[0];

for (i = 0; i < count; i++) {
    values[i] = 0;
}
```

`sizeof values`は配列全体の大きさ（バイト数）、`sizeof values[0]`は要素1個分の大きさです。
これらを割り算することで、要素数（この例では10）を自動で求められます。
`size_t`は、大きさや個数を表すためのマイナスにならない整数型で、`stddef.h`に含まれています。

### 終了条件を更新する

ループの中で、終了条件に関わる変数の値が変わらないままだと、条件がずっと真のままになり、ループが永遠に終わりません。

```c
int i = 0;

while (i < 10) {
    printf("%d\n", i);
    i++;
}
```

`while`文を書くときは、`i++;`のように「ゴールへ近づく更新処理」が確実に実行されるか確認しましょう。

### 空文を確認する

`for (...)`のすぐ後ろにうっかりセミコロン`;`を付けてしまうと、そこが「何もしない文（**空文**）」になり、ループの中身が空っぽになってしまいます。

```c
for (i = 0; i < 10; i++); /* Empty loop body. */
{
    printf("executed once\n");
}
```

このコードでは、何もしない処理が10回繰り返された後、その下の`{ ... }`がループとは無関係に1回だけ実行されます。
`for`や`while`のカッコの直後にセミコロンを付けないよう気をつけましょう。

## C99以降との違い

C99以降の新しい規格では、`for`文の初期化の部分でループ変数を直接宣言できるようになりました。

```c
for (int i = 0; i < 10; i++) {
    printf("%d\n", i);
}
```

この書き方をすると、変数`i`が使える有効範囲（**スコープ**）はその`for`文の中だけに限定されるため、外側の変数と名前がぶつかるのを防ぎやすくなります。
