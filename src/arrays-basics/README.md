# 第7章：配列の基本

## 対応するC規格

- **主要対象**：C90
- **学習内容**：1次元配列、多次元配列、初期化、走査、検索、集計

## 学習目標

この章では、同じ型のデータを1か所にまとめて並べて管理できる**配列**を学びます。
たとえばクラス全員のテストの点数を1つずつ別の変数にする代わりに、番号つきのロッカーのようにまとめて扱えるようになります。

- 配列を宣言して、最初の値（初期値）を入れられる
- 安全に使える番号（添字）の範囲を説明できる
- ループを使って配列の中から値を探したり、合計や平均を計算したりできる
- 2次元配列の「行」と「列」を正しく扱える
- 配列とポインターを同じものと思わず、変換が起こる場面を説明できる

## 配列とは

**配列**は、同じ型のデータ（**要素**）をメモリの上にすき間なく連続して並べたものです。
番号つきのロッカーが横一列にずらっと並んでいるイメージを思い浮かべてみてください。

次の宣言は、`int`型の箱を5個並べた配列`values`を作ります。

```c
int values[5];
```

それぞれの箱には通し番号がついており、この番号を**添字**（そえじ）と呼びます。
C言語では、**添字は必ず`0`から始まります**。
要素数が5個なら、安全に使える添字は`0`、`1`、`2`、`3`、`4`の5つです。

```c
values[0] = 10;
values[4] = 50;
```

上のコードでは、1番目の箱（添字`0`）に`10`を、5番目の箱（添字`4`）に`50`を入れています。

ここで最も大切な注意点があります。
`values[5]`は「6番目の箱」を意味しますが、5個しか作っていないため存在しません。
このような配列の範囲を超えたアクセスを行うと、C言語では何が起こるかわからない危険な状態（**未定義動作**）になります。
C言語はプログラムの実行中に「添字が範囲におさまっているか」を自動でチェックしてくれないため、自分で範囲を守る必要があります。

## 配列の宣言

C90の固定長配列では、要素数として`0`より大きい固定の整数（整数定数式）を指定します。
あらかじめ`#define`で要素数に名前をつけておくと、あとから人数や個数を変えたくなったときに1か所直すだけで済むため便利です。

```c
#define SCORE_COUNT 5

int scores[SCORE_COUNT];
```

配列の要素にする型は、1個あたりの大きさがはっきり決まっている型（完全オブジェクト型）である必要があります。
また、一度作った配列の要素数を、プログラムの途中で増やしたり減らしたりすることはできません。

## 配列の初期化

配列を作るときに、波括弧`{ }`を使って最初の値（初期値）をまとめて入れられます。

すべての要素の値を並べて書く方法です。

```c
int values[5] = { 10, 20, 30, 40, 50 };
```

書いた値の数が要素数より少ない場合、残りの箱には自動で`0`が入ります。

```c
int values[5] = { 1, 2 }; /* { 1, 2, 0, 0, 0 } */
```

`[]`の中の要素数を省略すると、書いた値の個数からコンパイラが自動で要素数を決めてくれます。

```c
int values[] = { 10, 20, 30 };
```

すべての要素をまとめて`0`で初期化したいときは、次のように書くのが定番です。

```c
int values[100] = { 0 };
```

先頭の1個を`0`にすると、残りの99個もすべて自動で`0`になります。

なお、一度作った配列に対して、別の配列を`=`でまるごと代入することはできません。
C言語のルール違反（制約違反）となり、コンパイルエラーになります。

```c
int a[3] = { 1, 2, 3 };
int b[3];

/* b = a; */ /* Constraint violation. */
```

配列の中身を別の配列へコピーしたいときは、次のようにループで1個ずつコピーするか、標準ライブラリ関数を使います。

```c
int i;

for (i = 0; i < 3; i++) {
    b[i] = a[i];
}
```

## 配列を走査する

配列の先頭から末尾まで、1つずつ順番に要素を見て回る処理を**走査**（そうさ）と呼びます。
走査するループでは、添字を`0`から始めて「要素数未満」のあいだ繰り返します。

```c
#include <stddef.h>
#include <stdio.h>

int main(void)
{
    int values[] = { 10, 20, 30, 40, 50 };
    size_t count = sizeof values / sizeof values[0];
    size_t i;

    for (i = 0; i < count; i++) {
        printf("%d\n", values[i]);
    }

    return 0;
}
```

`sizeof values`は配列全体の大きさ（バイト数）、`sizeof values[0]`は要素1個分の大きさです。
これらを割り算する`sizeof values / sizeof values[0]`によって、配列の要素数を自動で計算できます。

ただし、この計算方法が使えるのは`values`が「配列そのもの」として見えている場所だけです。
関数の引数（仮引数）として受け取った配列には使えない点に注意してください。

## 線形探索

配列の先頭から1個ずつ順番に調べて、探している値を見つける方法を**線形探索**（せんけいたんさく）と呼びます。
見つかったらその場所の添字を返し、最後まで見つからなかったときは、添字としてはありえない負の数（`-1`）を返すのが一般的です。

```c
int find_value(const int values[], int count, int target)
{
    int i;

    for (i = 0; i < count; i++) {
        if (values[i] == target) {
            return i;
        }
    }

    return -1;
}
```

仮引数についている`const`は、「この関数の中では配列の中身を書き換えない」という約束を表すキーワードです。

また、関数の仮引数として書いた`const int values[]`は、C言語のルールによって先頭要素へのポインター`const int *values`へ自動で読み替えられます（調整されます）。
そのため、配列の要素数までは関数へ自動で伝わりません。
関数に配列を渡すときは、要素数`count`も別の引数として一緒に渡します。

## 最大値、最小値、平均

配列の中から一番大きい値（最大値）を探すときは、まず最初の要素`values[0]`を「今のところのチャンピオン」として変数`max`に入れます。
その後、2番目以降の要素と順番に比べて、もっと大きい数が見つかったら`max`を更新していきます。

ただし、もし要素数が0以下だったり、渡されたポインターが空っぽ（`NULL`）だったりすると、`values[0]`を読むことができません。
そのため、最初に必ず「要素数が1以上あるか」「`NULL`ではないか」をチェックします。

```c
#include <stddef.h>

int max_value(const int values[], int count, int *result)
{
    int i;
    int max;

    if (values == NULL || result == NULL || count <= 0) {
        return 0;
    }

    max = values[0];

    for (i = 1; i < count; i++) {
        if (values[i] > max) {
            max = values[i];
        }
    }

    *result = max;
    return 1;
}
```

この関数は、計算に失敗したときは`0`を、成功したときは`*result`に最大値を書き込んで`1`を返します。

次は、配列の平均値を求める例です。
平均を求めるときは、要素数`count`が0のときに割り算をしないよう（**0による除算**を避けるため）先にチェックします。

```c
#include <stddef.h>

double average(const int values[], int count)
{
    long sum = 0;
    int i;

    if (values == NULL || count <= 0) {
        return 0.0;
    }

    for (i = 0; i < count; i++) {
        sum += values[i];
    }

    return (double)sum / count;
}
```

合計を入れる変数`sum`に`int`ではなく`long`を使っているのは、たくさんの数を足したときに型の最大値を超えてしまう（**オーバーフロー**）のを防ぎやすくするためです。
最後の`(double)sum / count`では、`sum`を小数（`double`型）に変換してから割ることで、小数点以下まで正しく計算しています。

なお、この例でも要素数や値がとても大きい場合は、`long`の足し算でもオーバーフローする可能性があります。
実際のプログラムでは、入力の上限をあらかじめ決めてから適切な型を選んでください。

## 要素を逆順に並べる

配列の中身を逆の順番に並べ替えるには、左端（`left`）と右端（`right`）の要素を交換しながら、少しずつ真ん中へ近づけていきます。

```c
void reverse(int values[], int count)
{
    int left = 0;
    int right = count - 1;

    while (left < right) {
        int temporary = values[left];
        values[left] = values[right];
        values[right] = temporary;
        left++;
        right--;
    }
}
```

2つのコップの中身を入れ替えるとき、一時的に中身を移しておく3つ目のコップが必要になります。
変数`temporary`は、その「一時的な避難場所」の役割をしています。

このコードはC90でも有効です。
変数`temporary`が、`while`の波括弧`{ }`（複合文）の先頭で、ほかの処理より前に宣言されているからです。

## 2次元配列

表計算ソフトの表やオセロの盤面のように、「行（横の列）」と「列（縦の列）」があるデータは、**2次元配列**で表します。
C言語の2次元配列は、「配列を要素として持つ配列」です。

次の`matrix`は、「`int`を4個持つ配列」を3行まとめた2次元配列です。

```c
int matrix[3][4];
```

要素には`matrix[row][column]`のように、行番号と列番号の2つの添字でアクセスします。
この例では、有効な行の添字は`0`から`2`、列の添字は`0`から`3`までです。

初期化するときは、次のように行ごとに波括弧でまとめると表の形が見やすくなります。

```c
int matrix[2][3] = {
    { 1, 2, 3 },
    { 4, 5, 6 }
};
```

C言語の多次元配列は、**行優先**でメモリ上に1列に連続して並びます。
この例では、まず1行目の`matrix[0][0]`、`matrix[0][1]`、`matrix[0][2]`が並び、そのすぐ後ろに2行目の`matrix[1][0]`から`matrix[1][2]`が続きます。

2次元配列の中身をすべて表示するには、入れ子の`for`文を使います。

```c
int row;
int column;

for (row = 0; row < 2; row++) {
    for (column = 0; column < 3; column++) {
        printf("%d ", matrix[row][column]);
    }

    printf("\n");
}
```

2次元配列を関数へ渡すときは、コンピューターが「次の行へ移動するには何個分進めばよいか」を計算できる必要があります。
そのため、列数（この例では`3`）を省略せずに型に含めます。

```c
void print_matrix(const int matrix[][3], int rows)
{
    int row;
    int column;

    for (row = 0; row < rows; row++) {
        for (column = 0; column < 3; column++) {
            printf("%d ", matrix[row][column]);
        }

        printf("\n");
    }
}
```

## 配列からポインタへの変換

C言語には、メモリ上の場所（アドレス）を記憶する**ポインター**という仕組みがあります。
配列の名前を式の中で使うと、多くの場面で「配列の先頭要素へのポインター（`&values[0]`）」に自動で変換されます。

ただし、`sizeof`で大きさを調べるときや、`&`を付けて配列全体のアドレスを取るときなど、一部の場面ではこの変換は起こりません。

```c
int values[5];
int *first = values;       /* &values[0] */
size_t bytes = sizeof values;
```

上の例では、`first`に配列の先頭要素のアドレスが入る一方、`sizeof values`はポインターの大きさではなく配列全体のバイト数を返します。

配列（ロッカーの本体）とポインター（ロッカーの場所を書いたメモ）はまったく別の型であり、同じものではありません。
この違いは、次の章でじっくり学びます。

## よくある誤り

配列を使い始めたときによく起きる3つのミスを確認しておきましょう。

### 範囲外アクセス

要素数が5の配列で有効な添字は`0`から`4`までです。
`values[5]`への書き込みは範囲外アクセスとなり、未定義動作を引き起こします。

```c
int values[5] = { 0 };
values[5] = 10; /* Undefined behavior. */
```

### 初期化前の読み取り

初期値を入れずに作ったローカル配列の中身は、何が入っているかわからないゴミのような値（不定値）になっています。
値を読み取る前に、必ず初期化するか値を代入しましょう。

```c
int values[5];
printf("%d\n", values[0]); /* Indeterminate value. */
```

### バイト数と要素数の混同

`sizeof values`が返すのは、要素の「個数」ではなくメモリ上の「バイト数」です。
要素の個数を知りたいときは、必ず1個分の大きさ`sizeof values[0]`で割ります。

```c
int values[10];
size_t bytes = sizeof values;
size_t count = sizeof values / sizeof values[0];
```

`bytes`はバイト数、`count`は要素数です。

## C99で追加された配列機能

C99以降の新しい規格では、番号を指定して初期値を入れられる**指定初期化子**、名前をつけずに一時的な配列を作れる**複合リテラル**、実行時に要素数を決められる**可変長配列**が追加されました。
なお、C11とC17では、可変長配列に対応しているかどうかはコンパイラ（処理系）ごとの任意機能になっています。

次は、指定初期化子を使って2番目と7番目だけに値を入れる例です（残りは自動で`0`になります）。

```c
int values[10] = { [2] = 5, [7] = 9 };
```
