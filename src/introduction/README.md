# 第1章：はじめてのC言語

## 学習目標

この章では、C言語のプログラムを書き、コンピューターが動かせる形へ変換（コンパイル）して実行するまでの流れを学びます。

- C言語がどのような場面で使われているか説明できる
- コンパイラ（プログラムを翻訳するソフト）を準備し、動くか確認できる
- `Hello, World!`と画面に表示するプログラムを作れる
- コンパイルと実行の違いを区別できる

## C言語が使われる分野

C言語は、パソコンやスマートフォン全体を動かす基本ソフト（オペレーティングシステム：OS）や、家電・ゲーム機の中に入っている小さなコンピューター（組込み機器）などで広く使われています。
また、ほかのプログラミング言語を動かす仕組み（処理系）や、速さが求められる部品集（ライブラリ）を作るときにも選ばれます。

C言語の特徴は、メモリ（データを覚えておく番号つきのロッカーのような場所）や、CPUなどの機械そのもの（ハードウェア）に近い動きを細かく指定できる点です。
その代わり、データの入れ物からはみ出さないようにする管理（配列の境界チェック）や、使い終わったメモリを片づける管理（メモリの寿命管理）は、プログラムを書く人自身が責任を持って行います。

C言語を学ぶと、プログラムがコンピューターの中でどのように動いているかが見えてきます。
たとえば、データを入れる箱（変数）がメモリにどう置かれるのか、人間が書いた文章（ソースコード）がどうやって動くファイル（実行可能ファイル）へ変わるのかを理解できます。
さらに、どのパソコンでも必ず同じ動きになる公式のルール（規格で保証される動作）と、使うパソコンや翻訳ソフトによって変わりうる動き（処理系に依存する動作）の違いも区別できるようになります。

## 開発環境

C言語のプログラムを作るには、次の2つの道具が必要です。

- **テキストエディタ**：プログラムの文章を書くためのソフト（メモ帳の高機能版のようなもの）
- **Cコンパイラ**：人間が書いたC言語の文章を、コンピューターが直接理解できる言葉へ翻訳するソフト

コンパイラをインストールしたら、キーボードで命令を打ち込む画面（macOSやLinuxでは「ターミナル」、Windowsでは「コマンドプロンプト」）を開き、次のコマンドを実行してください。

```bash
gcc --version
```

バージョン番号などの情報が表示されれば、`gcc`コマンドを使う準備ができています。
使っている環境によっては、コンパイラのコマンド名が`gcc`ではなく`clang`の場合もあります。

### Windows

Windowsでは、MinGW-w64など、GCCというコンパイラが入った開発環境を利用できます。
インストール手順や`PATH`（コマンドを探す場所を登録する設定）の方法は配布元によって異なるため、利用する配布パッケージの案内に従ってください。

### macOS

macOSでは、Appleが提供している「Command Line Tools」を入れるとコンパイラを使えます。
ターミナルで次のコマンドを実行してインストールします。

```bash
xcode-select --install
```

### UbuntuとDebian

UbuntuやDebianなどのLinuxでは、`build-essential`というまとめセット（パッケージ）を入れると、GCCや`make`（ビルドを自動化する道具）などの基本ツールが一度にそろいます。

```bash
sudo apt update
sudo apt install build-essential
```

## 最初のプログラム

テキストエディタで`hello.c`という新しいファイルを作り、次のコードをそのまま入力して保存します。
ファイル名の末尾にある`.c`は、「C言語のソースファイルですよ」という目印です。

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

短いプログラムですが、1行ごとに大切な役割があります。

- `#include <stdio.h>`は、画面への文字表示やキーボード入力に使う道具箱の説明書（ヘッダファイル）を読み込む命令です。
    これを書くことで、`printf`という命令を使えるようになります。
- `int main(void)`は、プログラムが動き始めるときに一番最初に呼ばれるスタート地点（`main`関数）を作る行です。
    `void`は「スタート時に受け取る材料がない」という意味で、先頭の`int`は「終わったら整数で結果を返す」という意味です。
- `{`から`}`までの間に、実際に動かしたい処理を書きます。
- `printf("Hello, World!\n");`は、画面（標準出力）へ`Hello, World!`という文字を表示する命令です。
    末尾の`\n`は「ここで改行する」という特別な合図で、最後の`;`（セミコロン）は日本語の句点にあたる文の区切りです。
- `return 0;`は、パソコン（OS）へ「エラーなく無事に終わりました」という意味の`0`を返してプログラムを終了する命令です。

## コンパイルと実行

C言語では、ソースコードを書いただけではまだ動きません。
まず**コンパイル**という作業で、人間が書いた`hello.c`から、コンピューターがそのまま動かせる**実行可能ファイル**を作ります。

コンパイルするときは、あやしい書き方やルール違反を早めに教えてもらうために、警告（ワーニング）を出す設定をつけておくと安心です。
ターミナルで次のコマンドを実行します。

```bash
gcc -std=c90 -Wall -Wextra -pedantic hello.c -o hello
```

このコマンドの各部分には、次のような意味があります。

- `-std=c90`：C90という標準ルールに沿ってチェックする指定です。
- `-Wall -Wextra -pedantic`：間違いの原因になりそうな書き方を見逃さず、ていねいに警告を出す指定です。
- `hello.c`：翻訳のもとになるソースファイルです。
- `-o hello`：できあがる実行可能ファイルの名前を`hello`にする指定です。

何もエラーが出ずにコンパイルが成功したら、いよいよできあがったプログラムを**実行**します。
macOSやLinuxでは、今いるフォルダの中にある`hello`を動かすために、先頭に`./`をつけて実行します。

```bash
./hello
```

Windowsのコマンドプロンプトでは、作られた実行ファイル名（`.exe`がついたファイル）を指定します。

```text
hello.exe
```

画面に次のように表示されれば成功です。

```text
Hello, World!
```

このように、「ソースコードを翻訳して実行ファイルを作ること」が**コンパイル**、「できあがった実行ファイルを実際に動かすこと」が**実行**です。
ソースコードを書き換えたら、もう一度コンパイルしてから実行し直す必要があります。

## 文字列を入力するプログラム

次は、キーボードから名前を入力してもらい、その名前にあいさつを返すプログラムです。
ここでは、空白（スペース）を含まない名前を読み取る例を確認します。

C言語では、文字の並び（文字列）の最後に「ここで終わりだよ」という目印（終端文字`'\0'`）が1文字分必要です。
そのため、`scanf`という入力命令を使うときは、読み取れる最大の文字数を「入れ物の大きさより1小さい数」に指定して、終端文字のスペースを必ず残しておきます。

```c
#include <stdio.h>

int main(void)
{
    char name[50];

    printf("Name: ");
    if (scanf("%49s", name) != 1) {
        return 1;
    }

    printf("Hello, %s!\n", name);
    return 0;
}
```

このプログラムは、次の流れで動きます。

1. `char name[50];`で、文字を50個分入れられる箱の並び（配列）を用意し、`name`という名前をつけます。
2. `printf("Name: ");`で、入力をうながす文字を画面に出します。
3. `scanf("%49s", name)`で、キーボードから最大49文字まで読み取って`name`へ入れます。
    残りの1文字分は、終わりの目印`'\0'`のために空けてあります。
4. `if (scanf("%49s", name) != 1)`は、「ちゃんと1つの文字列を読み取れたか」を確かめるチェックです。
    読み取りに失敗した場合は、`return 1;`で「うまくいかなかった」と伝えて終了します。
5. 無事に読み取れたら、`printf("Hello, %s!\n", name);`の`%s`の部分に`name`の中身をはめ込んで表示します。

もし`%49s`ではなく`%s`だけを書くと、長すぎる文字が入力されたときに`name`の入れ物からはみ出してしまい、とても危険です。
また、`scanf`の`%s`は空白を見つけるとそこで入力を区切るため、`Taro Yamada`のように空白が入った名前全体は一度に読み取れません。
空白を含めて1行まるごと安全に読み取る方法は、文字列の章で学びます。

## 付属コードのビルド

この章のフォルダには、`Makefile`という「コンパイル手順をまとめたレシピ」のようなファイルが用意されています。
`make`コマンドを使うと、付属のサンプルプログラムをまとめてビルド（コンパイルして実行ファイルを作ること）できます。

```bash
make all
make run-hello_world
make clean
```

- `make all`：この章のサンプルプログラムをすべてコンパイルします。
- `make run-hello_world`：`hello_world`プログラムを実行します。
- `make clean`：作られた実行ファイルを片づけます。

実装例は、次のファイルにあります。

- [hello_world.c](examples/hello_world.c)
- [greeting.c](examples/greeting.c)
