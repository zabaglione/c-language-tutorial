## C言語の歴史

C言語は1972年にデニス・リッチーがベル研究所で開発したプログラミング言語です。

### C言語誕生の背景

1. **1969年**: Ken ThompsonがB言語を開発
2. **1972年**: Dennis RitchieがC言語を開発
3. **1973年**: Unix OSをC言語で書き直し
4. **1978年**: K&R C（最初のC言語の本）出版
5. **1989年**: ANSI C（C89）標準化
6. **1990年**: ISO C（C90）国際標準化

### なぜ標準化が必要だったか？

- 異なるコンパイラで同じコードが動かない問題
- プログラムの移植性を保証する必要性
- 言語仕様を明確に定義する必要性

## C言語規格の詳細

### C言語規格の歴史

| 規格名 | 発表年 | 正式名称 | 主な特徴 |
|--------|--------|----------|----------|
| **C90** | 1990年 | ISO/IEC 9899:1990 | 初の国際標準、ANSI C |
| **C99** | 1999年 | ISO/IEC 9899:1999 | _Bool型、可変長配列、inline関数 |
| **C11** | 2011年 | ISO/IEC 9899:2011 | 匿名構造体、_Generic、マルチスレッド |
| **C17** | 2018年 | ISO/IEC 9899:2018 | C11のバグ修正版 |
| **C23** | 2023年 | ISO/IEC 9899:2023 | typeof、_BitInt、改良された型推論 |

### 各規格の詳しい説明

#### C90（ANSI C）

- C言語の最初の国際標準規格
- 最も基本的で、すべてのC言語コンパイラが対応
- シンプルで学習しやすく、初心者にお勧め
- 古い組込みシステムでも確実に動作

**主な特徴:**

- 関数プロトタイプの導入
- void型、const、volatileキーワード
- 標準ライブラリの定義

#### C99

- 多くの便利な機能が追加された大規模アップデート
- 現在最も広く使われている規格

**主な新機能:**

- forループ内での変数宣言
- 可変長配列（VLA）
- inline関数
- _Bool型（stdbool.hでboolとして使用可能）
- //形式のコメント
- 複合リテラル
- 指定初期化子

```c
/* C99の新機能例 */
#include <stdbool.h>

int main(void) {
    /* forループ内での変数宣言 */
    for (int i = 0; i < 10; i++) {
        printf("%d\n", i);
    }

    /* bool型の使用 */
    bool flag = true;

    /* 可変長配列 */
    int n = 5;
    int array[n];  /* C99から可能 */

    /* 指定初期化子 */
    int arr[10] = {[0] = 1, [5] = 2, [9] = 3};

    return 0;
}
```

#### C11

- マルチスレッドのサポートが追加
- より安全なプログラミングのための機能強化

**主な新機能:**

- スレッドライブラリ（threads.h）
- アトミック操作（stdatomic.h）
- _Generic（型に応じた処理の選択）
- _Static_assert（コンパイル時アサーション）
- 匿名構造体・共用体
- _Alignas、_Alignof

```c
/* C11の新機能例 */
#include <stdio.h>

/* _Static_assertの使用 */
_Static_assert(sizeof(int) == 4, "int must be 4 bytes");

/* _Genericの使用 */
#define TYPE_NAME(x) _Generic((x), \
    int: "integer", \
    float: "float", \
    double: "double", \
    default: "other")

int main(void) {
    int i = 42;
    float f = 3.14f;

    printf("i is %s\n", TYPE_NAME(i));    /* "i is integer" */
    printf("f is %s\n", TYPE_NAME(f));    /* "f is float" */

    return 0;
}
```

#### C17

- C11の細かいバグを修正したマイナーアップデート
- 新機能の追加はほとんどなし
- より安定した規格

#### C23

- 最新の規格（2023年公開）
- より使いやすい言語を目指した改良

**主な新機能:**

- typeof演算子
- _BitInt（任意ビット幅整数）
- #embed（バイナリデータの埋め込み）
- 改良された型推論
- nullptr定数

## どの規格を選ぶべきか？

### 用途別の推奨規格

#### 学習目的

- **C90から始める**
    - 最も基本的な機能を確実に習得
    - どこでも動く汎用的なコード
    - 段階的に新しい機能を学べる

#### 実用的なプログラム開発

- **C99を使う**
    - 便利な機能で生産性向上
    - ほとんどの環境で問題なく動作
    - 現在の業界標準

#### 組込みシステム開発

- **C90またはC99**
    - マイコンやコンパイラの対応状況を確認
    - 古い環境ではC90のみの場合あり

#### 最新機能を使いたい

- **C11/C17**
    - マルチスレッドプログラミング
    - より安全なコード記述
    - モダンな開発環境が必要

## 規格による違いの例

### 変数宣言の位置

```c
/* C90スタイル - 変数宣言は関数の先頭 */
int main(void) {
    int i;
    int sum = 0;

    for (i = 0; i < 10; i++) {
        sum += i;
    }

    return 0;
}

/* C99以降のスタイル - 使用する場所で宣言 */
int main(void) {
    int sum = 0;

    for (int i = 0; i < 10; i++) {
        sum += i;
    }

    return 0;
}
```

### コメントの書き方

```c
/* C90 - ブロックコメントのみ */
/* これはコメントです */
/*

 * 複数行の
 * コメント

 */

/* C99以降 - 行コメントも使用可能 */
// これもコメントです
// より簡潔に書ける
```

## コンパイラーでの規格指定

```bash

# C90準拠

gcc -std=c90 -pedantic program.c

# C99準拠

gcc -std=c99 -pedantic program.c

# C11準拠

gcc -std=c11 -pedantic program.c

# C17準拠

gcc -std=c17 -pedantic program.c

# C23準拠（コンパイラーが対応している場合）

gcc -std=c23 -pedantic program.c
```

## この章のまとめ

- C言語は50年以上の歴史を持つ言語
- 時代とともに進化し、複数の規格が存在
- 初学者はC90から始めて、徐々に新機能を学ぶのがおすすめ
- 実務ではC99が最も一般的
- プロジェクトの要件に応じて適切な規格を選択することが重要
