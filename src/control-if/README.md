# 第5章：条件分岐

## 対応するC規格

- **主要対象**：C90
- **学習内容**：`if`、`else`、`switch`、条件演算子、条件式の注意点

## 学習目標

この章では、「もし〇〇ならAをする、そうでなければBをする」のように、条件に合わせて実行する処理を選ぶ**条件分岐**を学びます。

- `if`文と`if-else`文を正しく書ける
- 複数の条件を調べる順番を自分で設計できる
- `switch`文の`case`、`break`、フォールスルーの仕組みを説明できる
- 代入と比較の間違いや、小数を比べるときの落とし穴を避けられる

## 条件式

条件分岐では、「条件にあてはまるかどうか」を調べる式を使います。
この式のことを**条件式**と呼びます。

C言語（C90）では、条件式を計算した結果の数値によって、次のように判断します。

- 値が`0`なら**偽**（条件にあてはまらない、いいえ）
- 値が`0`以外ならすべて**真**（条件にあてはまる、はい）

大きさを比べる記号（`>`や`==`などの**関係演算子**）や、条件を組み合わせる記号（`&&`や`||`などの**論理演算子**）を使って計算した結果は、`int`型の`0`（偽）または`1`（真）になります。

次の例では、個数を表す変数`count`が`0`より大きいときだけ、画面にメッセージを表示します。

```c
if (count > 0) {
    printf("items available\n");
}
```

`count`が`3`なら`count > 0`は真（`1`）になるため、`items available`と表示されます。
`count`が`0`なら偽（`0`）になるため、何も表示されません。

## `if`文

`if`は英語で「もし〜なら」という意味です。
`if`文は、条件が真（あてはまる）のときだけ、決められた処理を実行します。

```c
if (condition) {
    statement;
}
```

波括弧`{`と`}`で囲んだかたまりを**ブロック**と呼びます。
条件が真のとき、このブロックの中に書いた処理が上から順番に実行されます。

ブロックの中の処理が1行だけでも、波括弧`{ }`を付けておくのがおすすめです。
後から処理を増やしたときに、思わぬミスを防げるからです。

次の例では、テストの点数`score`が60点以上のときに「合格」と表示し、さらに合格人数を数える`passed_count`を1増やしています。

```c
if (score >= 60) {
    printf("passed\n");
    passed_count++;
}
```

もし波括弧を省略してしまうと、`if`がコントロールできるのは**すぐ後ろの1文だけ**になります。

```c
if (score >= 60)
    printf("passed\n");
passed_count++; /* Always executed. */
```

上のコードでは、`score`が50点（不合格）のときでも、`passed_count++`は`if`の外側にあるため毎回実行されてしまいます。
見た目の字下げ（インデント）をそろえていても、C言語では波括弧がないと1文しか中に入らない点に注意しましょう。

## `if-else`文

「条件にあてはまるときはA、あてはまらないときはB」のように、2つの道からどちらか1つを選びたいときは、`if-else`文を使います。
`else`は英語で「そうでなければ」という意味です。

```c
if (age >= 18) {
    printf("adult\n");
} else {
    printf("minor\n");
}
```

この例では、`age`が18以上なら`adult`、18未満なら`minor`と表示されます。
どちらか片方だけが必ず実行されます。

また、ユーザーからの入力を使うプログラムでは、ふつうの処理（正常系）を書く前に、**まちがった入力（不正値）を先にチェックしてはじく**と読みやすくなります。
銀行のATMでお金を引き出す処理をイメージしてみましょう。

```c
if (amount <= 0) {
    printf("invalid amount\n");
} else if (amount > balance) {
    printf("insufficient balance\n");
} else {
    balance -= amount;
    printf("withdrawal completed\n");
}
```

1つ目で「引き出す金額`amount`が0円以下ではないか」、2つ目で「残高`balance`より多くないか」を先に調べています。
そのどちらにも当てはまらない安全なときだけ、最後の`else`で残高からお金を引いています。
このように先にダメな条件をはじいておくと、条件が何重にも重なる（入れ子が深くなる）のを防げます。

## `else if`による複数分岐

選択肢が3つ以上あるときは、`else if`をつなげて書きます。
条件は**上から順番に**調べられ、**最初に真になった1つだけ**が実行されます。
一度どれかが実行されると、それより下の条件は調べられません。

次の例は、テストの点数`score`から成績（A〜F）を決めるプログラムです。

```c
if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else if (score >= 70) {
    grade = 'C';
} else if (score >= 60) {
    grade = 'D';
} else {
    grade = 'F';
}
```

条件の範囲が重なるときは、より限定された条件や、大きい区切りから順番に並べるのが大切なポイントです。

たとえば、もし`score >= 60`を一番上に書いてしまうと、90点の人も「60点以上」にあてはまってしまい、本当は`'A'`なのに`'D'`になってしまいます。
それぞれの条件がどの範囲を担当しているのか、上から順番にたどって確認してください。

## 入れ子の`if`文

ある条件にあてはまったときだけ、さらにもう1つ別の条件を調べたい場合があります。
そのときは、箱の中に箱を入れるように、`if`文の中に別の`if`文を書くことができます。
これを**入れ子**（ネスト）と呼びます。

次の例では、まず気温`temperature`が25度以上かどうかを調べます。
25度以上だった場合だけ、さらに雨が降っているか（`is_raining`）を調べてメッセージを変えています。

```c
if (temperature >= 25) {
    if (is_raining) {
        printf("warm and rainy\n");
    } else {
        printf("warm and dry\n");
    }
}
```

入れ子の`if`文で波括弧を省略すると、`else`は**対応できる一番近い`if`**に自動で結び付くルールがあります。
書いた本人のつもりとはちがう`if`にくっついてしまうことがあるため、入れ子では必ず波括弧を付けましょう。

また、2つの条件を同時に満たしたいだけなら、論理演算子`&&`（「かつ」という意味）で1つにまとめた方がすっきり読めることもあります。

```c
if (age >= 18 && has_license) {
    printf("eligible\n");
}
```

この例では、「18歳以上」かつ「免許を持っている（`has_license`が真）」の両方を満たすときだけ`eligible`（条件を満たしている）と表示します。

ただし、「年齢が足りない」「免許を持っていない」のように、条件ごとに別のエラーメッセージを出したいときは、1つにまとめずに分岐を分けて書きます。

## `switch`文

1つの変数の値を見て、「1ならこれ、2ならこれ、3ならこれ」のようにたくさんの候補から処理を選びたいときは、`switch`文が便利です。
ゲームのメニュー画面で番号を選ぶような場面に向いています。

`switch`文の`()`の中には、整数型（`int`や`char`など）または列挙型（`enum`）の式を書きます。
各`case`には、あらかじめ決まった重複しない整数の定数（あとから変わらない数）を指定します。

```c
switch (choice) {
case 1:
    printf("option 1\n");
    break;
case 2:
    printf("option 2\n");
    break;
default:
    printf("unknown option\n");
    break;
}
```

それぞれの役割は次のとおりです。

- `case 値:`：`choice`がその値と一致したときに、ここから処理を始める目印（ラベル）です
- `default:`：どの`case`にもあてはまらなかったときに実行される「その他」の受け皿です
- `break;`：もっとも内側にある`switch`文から外へ脱出する命令です

もし`break;`を書き忘れると、処理が止まらずに**すぐ下の`case`の処理まで続けて実行されてしまいます**。
この下に流れ落ちる動きを**フォールスルー**と呼びます。

### 意図的なフォールスルー

うっかり`break;`を忘れるとバグになりますが、わざとフォールスルーを使うとすっきり書ける場面もあります。

複数の値でまったく同じ処理をしたいときは、途中に処理を書かずに`case`を連続して並べます。
次の例では、文字`letter`が英語の小文字の母音（`a`、`e`、`i`、`o`、`u`）のどれかであれば、まとめて`vowel`と表示します。

```c
switch (letter) {
case 'a':
case 'e':
case 'i':
case 'o':
case 'u':
    printf("vowel\n");
    break;
default:
    printf("not a lowercase vowel\n");
    break;
}
```

また、ある`case`で処理をしたあと、わざと次の`case`の処理も続けて実行したい場合もあります。
次の例では、`level`が2のときに上級モードを有効にしたあと、続けてレベル1の基本モードも有効にしています。

```c
switch (level) {
case 2:
    enable_advanced_mode();
    /* Fall through. */
case 1:
    enable_basic_mode();
    break;
default:
    break;
}
```

このようなときは、`/* Fall through. */`のようにコメントを書いて、「`break`を書き忘れたのではなく、わざと次へ進めている」と読む人に伝えましょう。

なお、C90のルールでは、変数の宣言はブロックの先頭にしか書けません。
`case`ラベルのすぐ後ろでは変数を直接宣言できないため、変数を新しく作りたいときは波括弧`{ }`でブロックを作ります。

```c
switch (choice) {
case 1: {
    int value = read_value();
    use_value(value);
    break;
}
default:
    break;
}
```

## 条件演算子

**条件演算子**`?:`（3つの要素を使うため「三項演算子」とも呼ばれます）は、条件によって2つの式のうちどちらか1つを選ぶための記号です。

`条件 ? 真のときの値 : 偽のときの値`という形で書きます。

```c
int max = a > b ? a : b;
```

この例では、`a > b`が真（`a`の方が大きい）なら`a`を、偽なら`b`を選んで、変数`max`に入れます。

条件演算子は、値を選ぶだけの短い式に向いています。
複数の処理を行ったり、別の変数を書き換えるような動き（副作用）を含んだりするときは、無理に1行にまとめず、読みやすい`if-else`文で書きましょう。

## 条件式の注意点

条件分岐では、初心者がつまずきやすい定番の落とし穴が3つあります。
あらかじめ知っておくことで、見つけにくいバグを防げます。

### 代入と比較

C言語では、`=`と`==`はまったく別の意味を持ちます。

- `=`：右の値を左の変数に入れる（**代入**）
- `==`：左と右の値が等しいか調べる（**比較**）

もし`if`文の中で間違えて`=`を書いてしまうと、どうなるでしょうか。

```c
if (x = 10) {  /* Assigns 10, then tests it as true. */
    printf("executed\n");
}
```

このコードは「`x`と10が等しいか」を調べるのではなく、「`x`に10を代入する」処理になります。
代入した値である`10`は0以外（つまり真）とみなされるため、`x`にもともと何が入っていても必ず実行されてしまいます。

等しいかどうかを比べるときは、必ず`==`を使いましょう。

```c
if (x == 10) {
    printf("x is 10\n");
}
```

### 浮動小数点数の比較

`double`型などの小数（**浮動小数点数**）を`==`で比べるのにも注意が必要です。
コンピューターはすべての数を0と1の組み合わせ（2進数）で保存しているため、`0.1`や`0.2`のような小数をぴったり正確に表せないことがあります。
その結果、計算の途中で目に見えないほどわずかなズレ（誤差）が生まれることがあります。

そのため、小数の計算結果を比べるときは、「ぴったり等しいか」ではなく、「2つの数の差が、許せるくらい十分に小さいか」で判断します。

```c
#include <math.h>

if (fabs(a - b) <= tolerance) {
    printf("close\n");
}
```

`math.h`にある`fabs`関数は、小数の絶対値（マイナスを取った大きさ）を求める関数です。
`a - b`の差の大きさが、あらかじめ決めた許容範囲`tolerance`（たとえば`0.0001`など）以下なら「ほぼ等しい」と判断しています。

ただし、固定の許容範囲（絶対誤差）だけでは、とても大きい数（1億など）や、とても小さい数（0.0000001など）を比べるときにうまく合わないことがあります。
使う場面に合わせて、元の数の大きさに対する割合（相対誤差）も組み合わせて判断します。

### 条件式の末尾に置くセミコロン

`if (...)`のすぐ後ろに、うっかりセミコロン`;`を付けてしまうミスもよく起こります。

```c
if (condition); /* Empty statement. */
{
    printf("always executed\n");
}
```

C言語では、`;`だけでも「何もしない1つの文（**空文**）」という意味になります。
そのため上のコードは、「条件が真なら何もしない」という意味になり、その下にある`{ ... }`は`if`とは無関係なブロックとして毎回実行されてしまいます。
`if (...)`の後ろにはセミコロンを付けないよう気をつけましょう。

## コンパイル

この章のサンプルプログラムをコンピューターが実行できる形に変換（**コンパイル**）して動かすには、ターミナルで次のコマンドを実行します。

```bash
gcc -std=c90 -Wall -Wextra -pedantic examples/basic_if.c -o basic_if
./basic_if
```

Makefileを使ってまとめてビルドや実行を行う場合は、次のコマンドを実行します。

```bash
make all
make run-all
make clean
```

## C99以降との違い

C99以降の新しい規格では、処理を書いた後や`for`文の初期化の部分でも新しく変数を宣言できるようになりました。
ただし、条件分岐そのものの基本の書き方や、`0`を偽・`0`以外を真とするルールはC90とまったく同じです。
