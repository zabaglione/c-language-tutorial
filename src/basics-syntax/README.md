# 第2章：基本構文

## 対応するC規格

- **主要対象**：C90（1990年に定められたC言語の基本ルール）
- **学習内容**：プログラムの構造、`main`関数、`printf`関数、コメント、エスケープシーケンス

## 学習目標

この章では、短いCプログラムがどんな部品でできているかと、画面へ文字を表示する（標準出力）基本を学びます。

- `#include`、関数定義、文の役割を説明できる
- 標準ルールに沿った`main`関数を書ける
- `printf`の書式指定子と渡すデータの種類（型）を正しく合わせられる
- C90のルールで使えるコメントを書ける

## プログラムの構造

次のプログラムは、画面（標準出力）へ1行だけ文字を表示して終わります。

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

このプログラムは、大きく分けて3つの要素で成り立っています。

1. **`#include <stdio.h>`**：画面表示やキーボード入力などの基本機能を集めた「標準入出力ライブラリ」の説明書を取り込みます。
    これにより、`printf`という関数（まとまった処理をする部品）の名前と使い方をコンパイラへ知らせる「宣言」が読み込まれます。
    正しい宣言がないまま関数を呼び出してはいけません。
2. **`int main(void) { ... }`**：関数を新しく作る「関数定義」です。
    パソコンなどのOS上で動く通常の環境（ホスト環境）では、Cプログラムは必ず`main`関数からスタートします。
    処理の中身は波括弧`{`と`}`で囲みます。
3. **文**：`printf("Hello, World!\n");`や`return 0;`のような1つ1つの命令のことです。
    処理を行う文の末尾には、日本語の句点のようにセミコロン`;`を置きます。

## `main`関数

プログラムを起動するとき、後ろに追加の文字（コマンドライン引数）を渡さない場合は、次の形を使います。

```c
int main(void)
{
    return 0;
}
```

プログラムを起動するときに追加の情報を渡したい場合は、次のように`argc`と`argv`を受け取る形を使えます。
たとえば、ターミナルで`./app apple`のように実行すると、`apple`という文字をプログラムの中で受け取れます。

```c
#include <stdio.h>

int main(int argc, char *argv[])
{
    printf("Program: %s\n", argv[0]);

    if (argc > 1) {
        printf("First argument: %s\n", argv[1]);
    }

    return 0;
}
```

この2つの材料（引数）には、次の意味があります。

- `argc`：渡された引数の個数です（0以上の整数）。
    プログラム自身の名前も1つと数えるため、追加の文字がなくても通常は1になります。
- `argv`：渡された文字の並びをしまっておくリストです。
    `argc`が0より大きいとき、`argv[0]`はプログラム自身の名前を指します。
    追加の引数があれば、`argv[1]`に1つ目、`argv[2]`に2つ目が入ります。
    もし実行環境からプログラム名を取得できない場合、`argv[0][0]`は文字列の終わりを表す見えない文字（ヌル文字`'\0'`）になります。

`main`関数から`0`を返すと、OSへ「正常に終わりました」と伝わります。
エラーなどで異常終了したことを伝えたいときは、どの環境でも同じ意味として通じる値（移植可能な値）として、`<stdlib.h>`で定義されている`EXIT_FAILURE`を使えます。
なお、C99以降のルールでは`main`関数の最後まで到達すると自動的に`0`を返した扱いになりますが、この教材では終了状態がひと目でわかるように`return 0;`を必ず書きます。

また、古い解説などで`void main()`という書き方を見かけることがありますが、標準Cのホスト環境では規定された正しい形式ではありません。
`main`関数の戻り値の型には、必ず`int`を使ってください。

## `printf`関数

`printf`は、ひな型となる文章（書式文字列）の中に値をはめ込んで、画面（標準出力）へ書き出す関数です。
ひな型の中に書く`%d`や`%f`のような目印を**書式指定子**と呼びます。

とても大切なルールとして、書式指定子と、そこに渡すデータ（引数）の種類（型）は必ず一致させなければなりません。
一致しない場合は**未定義動作**（C言語のルール違反になり、変な値が出たり異常終了したりと何が起きるかわからない状態）になります。

| 指定子 | 対応する引数 | 用途 |
|---|---|---|
| `%d` | `int` | 符号付き10進整数（プラス・マイナスの整数） |
| `%u` | `unsigned int` | 符号なし10進整数（0以上の整数） |
| `%c` | `int`へ整数拡張された文字 | 1文字 |
| `%s` | `char *` | ヌル終端文字列（最後に`'\0'`がついた文字の並び） |
| `%f` | `double` | 固定小数点表記（ふつうの小数表示） |
| `%p` | `void *` | ポインター値（メモリの場所を表す番号） |

`printf`のように渡す引数の個数が毎回変わる関数（可変個引数関数）には、「小さい型のデータは自動的に大きい型へ広がってから渡される」という仕組み（既定の実引数拡張）があります。
具体的には、`float`（小さめの小数）は`double`（大きめの小数）へ、`char`（1文字）や`short`（小さい整数）は通常`int`へ変換されて渡されます。
そのため、`printf`で小数を表示するときの`%f`は、`double`型を受け取る決まりになっています。

実際の使い方を見てみましょう。

```c
#include <stdio.h>

int main(void)
{
    int age = 20;
    double height = 170.5;

    printf("Age: %d\n", age);
    printf("Height: %.1f cm\n", height);
    return 0;
}
```

このプログラムでは、`%d`の場所に`age`の`20`が、`%.1f`の場所に`height`の`170.5`がはめ込まれます。
`%.1f`の`.1`は、「小数点以下を1桁まで表示する」という指定です。

ちなみに、`printf`は画面へ書き出した文字の個数を戻り値として返します。
もし出力エラーが起きた場合はマイナスの値を返すため、出力が成功したか厳密に確認したいプログラムでは戻り値をチェックします。

### 書式指定の誤り

書式指定子の個数と、後ろに渡す引数の個数はぴったり同じにする必要があります。
次の例では、`%d`が3つあるので、整数も3つ渡しています。

```c
printf("%d + %d = %d\n", 10, 20, 30);
```

一方で、次の呼び出しは間違いです。
`%d`は`int`型の整数を期待しているのに、`double`型の小数である`value`を渡しているため、未定義動作になります。

```c
double value = 3.14;
printf("%d\n", value); /* Wrong format: undefined behavior. */
```

小数を表示したいときは、正しく`%f`を使います。

```c
printf("%f\n", value);
```

## エスケープシーケンス

`"..."`で囲んだ文字データ（文字列リテラル）の中には、改行のようにキーボードから直接そのまま書きにくい文字や、文字列の区切りに使う`"`自体を入れたいことがあります。
そんなときは、バックスラッシュ`\`（日本語環境では`¥`と表示されることがあります）から始まる2文字の組み合わせを使います。
これを**エスケープシーケンス**と呼びます。

| シーケンス | 意味 |
|---|---|
| `\n` | 改行（次の行へ移る） |
| `\t` | 水平タブ（一定の幅だけ間を空ける） |
| `\"` | ダブルクォート（`"`そのものを表示する） |
| `\\` | バックスラッシュ（`\`そのものを表示する） |
| `\a` | 警告音（ビープ音を鳴らす） |
| `\b` | バックスペース（カーソルを1文字戻す） |
| `\r` | 復帰（カーソルを行の先頭へ戻す） |

なお、警告音（`\a`）、バックスペース（`\b`）、復帰（`\r`）が実際に画面でどう動くかは、使っているターミナルなどの実行環境によって異なります。
たとえば、`\b`を使ったからといって、直前の文字が必ず画面から消えるとは限りません。

次のプログラムでは、よく使う4つのエスケープシーケンスを組み合わせています。

```c
#include <stdio.h>

int main(void)
{
    printf("First line\nSecond line\n");
    printf("Name\tScore\n");
    printf("Quote: \"C\"\n");
    printf("Path: C:\\Program Files\\App\n");
    return 0;
}
```

1行目の`printf`は途中の`\n`で改行し、2行目は`\t`で`Name`と`Score`の間をきれいに空けます。
3行目は`\"`を使って`"C"`と引用符つきで表示し、4行目は`\\`を2つ重ねることで1つの`\`を表示しています。

## コメント

**コメント**は、プログラムの中に人間向けのメモを残すための仕組みです。
コメントに書いた文章はコンパイラがすべて無視するので、プログラムの動きには一切影響しません。

C90のルールでは、`/*`から`*/`までで囲んだ部分がコメントになります。
注意点として、コメントの中にさらにコメントを入れること（入れ子）はできません。
最初の`*/`が見つかった時点でコメントが終わってしまうためです。

```c
/* This is a comment. */

/*
 * A comment can span
 * multiple lines.
 */
```

`//`から行の終わりまでをコメントにする「行コメント」は、あとから作られたC99という規格で標準化されました。
そのため、C90としてコンパイルするコードでは`//`を使わず、`/* ... */`を使います。

## C90とC99の違い

C言語には時代とともに改訂された規格があり、C90とC99では次のような違いがあります。

- **変数を宣言できる場所**：C90では、`{`と`}`で囲まれたかたまり（複合文）の中で、処理の文より前にまとめて変数を宣言する必要があります。
    C99では、処理の途中や`for`文の初期化部分でも変数を宣言できます。
- **コメントの書き方**：C90では`/* ... */`だけを使いますが、C99では`//`で始まる行コメントも使えます。
